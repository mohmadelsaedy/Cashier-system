# كاشير السوبر ماركت

نظام نقاط بيع (POS) كامل لسوبر ماركت في ملف واحد `index.html`، بدون سيرفر وبدون تثبيت.

## المميزات

- **البيع**: قراءة الباركود والـ QR بالقارئ أو بالكاميرا، باركود الميزان، خصم، ضريبة، دفع نقدي وبطاقة ومحفظة، تعليق الفواتير.
- **الفواتير**: طباعة على ورق الكاشير الحراري 80 مم مع كود QR، إعادة طباعة، مرتجع كامل، تصدير CSV.
- **المنتجات والمخزون**: أسعار شراء وبيع وهامش ربح، خصم تلقائي من المخزون، تنبيهات النواقص، توليد باركود وطباعة ملصقات، استيراد وتصدير CSV.
- **لوحة التحكم**: المبيعات والأرباح، أوقات الذروة، طرق الدفع، الأكثر مبيعًا، المبيعات حسب التصنيف، أداء الكاشيرية.
- **الورديات**: عهدة الدرج، سحب وإيداع، تقفيل بعدّ الفئات، حساب العجز والزيادة، تقرير تقفيل مطبوع.
- **المستخدمين والصلاحيات**: دخول برقم سري، 3 أدوار (مدير نظام، مشرف، كاشير)، موافقة المشرف على الإجراءات الحساسة، قفل تلقائي.

## التشغيل

افتح `index.html` في المتصفح. أول مرة هيطلب منك إنشاء حساب مدير النظام.

### النشر على GitHub Pages

1. ارفع الملفات على مستودع (repository) جديد.
2. من **Settings ← Pages** اختار الفرع `main` والمجلد `/ (root)` واضغط **Save**.
3. بعد دقيقة هيبقى النظام شغال على `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`.

## مكان حفظ البيانات

خارج Claude، البيانات بتتحفظ في **متصفح الجهاز نفسه** (localStorage):

- كل جهاز ليه بياناته المنفصلة، ومفيش مزامنة بين الأجهزة.
- مسح بيانات المتصفح بيمسح بيانات النظام. **خد نسخة احتياطية بانتظام** من الإعدادات.
- مساحة المتصفح حوالي 5 ميجا، وده بيكفي آلاف الفواتير. لما تكبر، خد نسخة احتياطية وامسح القديم.

## المتطلبات

- متصفح حديث (Chrome أو Edge مفضلين).
- إنترنت أول مرة لتحميل الخط والمكتبات (Chart.js و JsBarcode و qrcode-generator و html5-qrcode).
- الكاميرا محتاجة الصفحة تكون على `https`، وGitHub Pages بيوفر ده.

## اختصارات لوحة المفاتيح

| المفتاح | الوظيفة |
|---|---|
| F2 | البحث |
| F9 | الدفع |
| F8 | تعليق الفاتورة |
| `3*` قبل الباركود | إضافة 3 قطع |
| Esc | إغلاق النافذة |
